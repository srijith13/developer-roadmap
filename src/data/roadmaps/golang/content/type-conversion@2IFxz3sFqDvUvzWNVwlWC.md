# Type Conversion

Convert values between different types using `Type(value)` syntax. Go requires explicit conversion even between related types like `int` and `int64`. Converting unrelated types (like `string` to `int`) often requires a library or more complex handling. Common cases requiring conversion: assigning values between different types, function arguments, mixed-type operations, and API/database interactions.
For complex types like `slices`, `arrays`, `maps`, and `structs`, you must manually convert each element or field; Go does not provide automatic conversion for these.
